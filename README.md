# MrCrayFish's Furniture Mod (Legacy Continued) + Nosiphus Furniture Mod

The greatest furniture mod ever made, updated and extended for modern versions of Minecraft.

## Brief Content Overview
MrCrayFish's Furniture Mod (Legacy Continued) + Nosiphus Furniture Mod is a modernized continuation of the classic [MrCrayFish's Furniture Mod](https://www.curseforge.com/minecraft/mc-mods/mrcrayfish-furniture-mod) that started way back in 2011. It's all about adding furniture to Minecraft that looks like it fits in with the vanilla game, and utilizes vanilla textures so if you use a resource pack, the furniture automatically changes to use it too. You can use it to find furniture for every part of your house, including but not limited to the living room, kitchen, bathroom, bedroom, office, outdoor patio, pool, and so much more! Nosiphus Furniture Mod, once an addon for the original MrCrayFish's Furniture Mod that re-added blocks that hadn't been ported to any version newer than 1.12.2, is included and keeps its separate namespace so that users of the old mods can update seamlessly without worrying that their worlds will lose any of their decorations.

## Compatibility Disclaimer
Please note that CFM+NFM is not compatible with the legacy versions of MrCrayFish's Furniture Mod, and the old mod must be removed for this mod to run. However, all features of the 7.x releases are included in this mod, and have even received fixes as the old mod had several bugs in it. This limitation is only applicable to 1.20.1 right now, as versions for 1.19.2 and below still require CFM to be present for the time being.

## Backstory
In 2019, MrCrayFish decided to rewrite his original furniture mod from the ground up, and over the course of that rewrite, he eventually decided to go in an entirely different direction and eventually released his new mod, Refurbished. Even before this, however, the 7.x versions of the original mod were significantly lacking in their feature set. In 2021, I began working on a [pull request](https://github.com/MrCrayfish/MrCrayfishFurnitureMod/pull/723) to re-add significant amounts of what was missing. He didn't proceed with it, but he did give me permission to release an add-on, which became the Nosiphus Furniture Mod. A few years later, when it was apparent that Legacy was likely never going to receive any updates, I ported CFM to 1.21.1 as part of NFM, and rebranded the mod to MrCrayFish's Furniture Mod (Legacy Continued) + Nosiphus Furniture Mod. I also decided to port the mod to be multi-loader, so now, CFM+NFM is available on both (Neo)Forge and Fabric.

## Integration
CFM+NFM supports three external mods natively: [Every Compat](https://www.curseforge.com/minecraft/mc-mods/every-compat), [Just Enough Items](https://www.curseforge.com/minecraft/mc-mods/jei), and [YogMod](https://www.curseforge.com/minecraft/mc-mods/yogmod). When these mods are present, Every Compat allows full wood variants for all your modded woods to be available, JEI provides recipe information for blenders and chopping boards, and YogMod enables the beige color variants of furniture to be usable.

## Sphax PureBDcraft
We have long used Sphax PureBDcraft as our resource pack of choice, and while the blocks themselves do not need custom textures, the items and GUIs do. You can obtain them [here](https://bdcraft.net/community/viewtopic.php?t=9849). For versions before 1.20.1, you will also need to use the old patch for the original CFM, which is available [here](https://bdcraft.net/community/viewtopic.php?t=5765).
